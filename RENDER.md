# Размещение на Render Free

Проект подготовлен для запуска как **Web Service → Docker → Free**. `render.yaml` задаёт бесплатный тариф, регион Frankfurt, проверку `/health`, порт 8000 и случайный ключ API при создании через Blueprint.

При создании через **Public Git Repository** укажите ссылку на репозиторий, ветку `main`, Dockerfile `./Dockerfile`, тариф Free и следующие переменные вручную:

| Переменная | Значение |
|---|---|
| `PORT` | `8000` |
| `TOUR_DATA_DIR` | `/data` |
| `TOUR_AUTO_REFRESH` | `1` |
| `TOUR_MAX_SAVED_JOBS` | `100` |
| `TOUR_API_KEY` | Отдельный случайный секрет, не сохранять в Git |

Команда запуска уже указана в Dockerfile. Health Check Path: `/health`. Платный диск, базу Render Postgres и платный тариф создавать не нужно.

После запуска:

1. `/health` должен отвечать HTTP 200; `ready` станет true после сбора трёх разделов.
2. `/docs` открывает Swagger. Кнопка **Authorize** принимает значение `TOUR_API_KEY`.
3. `/api/status` показывает время сбора и ошибки. Все `/api/*` требуют заголовок `X-API-Key`.
4. Проверьте каталог и горящие предложения, затем выполните один поиск с будущими датами. Успешная сборка Docker ещё не подтверждает работу браузерного поиска в облаке.

## Ограничения бесплатного размещения

Render Free засыпает после 15 минут без входящих запросов. Во время сна обновление не выполняется. После пробуждения первому сбору требуется время. Локальная SQLite временная: после остановки или нового развёртывания снимки и история могут быть потеряны, данные собираются заново. Это демонстрационное размещение без постоянного хранения.

Доступно 512 МБ оперативной памяти. Для нашего Chromium требуется реальная проверка после запуска; при нехватке памяти сервис может перезапускаться. Автоматический переход на платный тариф не предусмотрен.

Источники условий: [Render Free](https://render.com/docs/free), [ресурсы](https://render.com/docs/compute-plans), [Docker](https://render.com/docs/docker).
